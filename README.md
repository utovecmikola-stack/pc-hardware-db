# ПК Комплектуючі — База даних (SQLite)

Навчальний проєкт реляційної бази даних для збереження та зв'язування товарів із категоріями.

## Структура та запит
У файлі `schema.sql` знаходиться код для створення таблиць, зовнішніх ключів (`FOREIGN KEY`) та запиту `JOIN`.
